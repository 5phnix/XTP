# From the golden save to gameplay (cargo xtask play, docs/dev/autopilot.md).
# Grand Theft Auto VI, Xbox Series build; RVAs of game_scarlett_master.exe,
# found by the run-world analysis (task 1383180b, docs/analysis/run-keys.md).
build b99f876b74d4a77f03af5f878223b27bd647b5c35a79d5decd9f716504239e93

# Start-up: the title's init is done and its front end (profile screen,
# intro, logo) is up.
wait u8 0x74e007c == 1 and u32 0x74e2c1c == 1 timeout 60s

# From the golden save the front end ends by itself once the title has done
# its start-up work, 17.6 to 116 s after the start by the machine's load:
# its flag drops to 0 as the world starts loading. Nothing to press.
wait u32 0x74e2c1c == 0 or time >= 150s

# In case: a save that waits on the profile screen ("PLAYER (A)") takes A.
# Nothing is pressed when the front end already ended.
repeat a every 2500ms until u32 0x74e2c1c == 0 timeout 60s

# The save loads into the world: the loading screen (0xab43664 = 0xe) gives
# way to the world's first frame, where the start-up flag 0x9e58138 drops
# and the in-game byte 0x74dfa9d is set.
wait u32 0xab43664 == 0 and u32 0x9e58138 == 0 and u8 0x74dfa9d == 1 timeout 180s

release
